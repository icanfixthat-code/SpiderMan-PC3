# Spider-Man | Portafolio Interactivo

Este proyecto es una página web de práctica inspirada en Spider-Man, realizada para la Práctica Calificada 03 del curso Hojas de Estilo en Cascada Avanzado.

## Tecnologías
- HTML5 para la estructura.
- Bootstrap 5 para el menú, columnas, botones y formulario responsivo.
- CSS para colores, transformaciones y animaciones.
- JavaScript sencillo para mostrar un aviso de demostración en el formulario.

## Efectos CSS utilizados
- `rotate(4deg)` para girar la primera tarjeta al pasar el mouse.
- `scale(1.06)` para agrandar la segunda tarjeta.
- `translateY(-16px)` para mover la tercera tarjeta.
- `transition` para que los movimientos sean suaves.
- `perspective`, `transform-style: preserve-3d`, `rotateX()` y `rotateY()` para girar una tarjeta en 3D.
- `@keyframes entrada` para mostrar el título con un movimiento hacia arriba.
- `@keyframes girar` para animar el círculo de carga infinitamente.

## Cómo abrir
Abrir el archivo `index.html` en un navegador con conexión a Internet para que cargue Bootstrap desde su CDN.

## Nota
El formulario es una demostración visual y no envía correos ni guarda mensajes.
